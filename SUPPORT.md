## Report what it found

The most useful thing is a report from a machine that freezes. Run `hangdoctor check --json > report.json` and attach the file to an [issue](https://github.com/vasmarfas/hangdoctor/issues), especially if hangdoctor found a driver or program it doesn't know yet — that is how the list of known leaks grows. The report contains process and driver names from your PC; look through it before posting.

A star on GitHub helps other people find the project.
